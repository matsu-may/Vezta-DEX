# Standalone DEX handoff — 2026-09-30

## Evidence and decisions

The original local read probe returned 4/4 Trading API quotes HTTP 200 while 3/4 wallet-state reads failed at the Polygon block-read stage. The original RPC's latest-block method timed out twice in five tries. After the owner replaced the RPC URL, 15/15 direct chain and latest-block reads were valid. Three restarted-API local runs returned wallet-state HTTP 200 in 12/12 cycles and quote HTTP 200 in 11/12 cycles; one state read took 13.1 seconds and one quote timed out after eight seconds. Follow-up direct Trading API quotes succeeded in both directions, and the final two local runs had 8/8 quote and 8/8 state success. The replacement RPC passed an initial read preflight; the full **funded rehearsal gate remains open** because pinned/receipt behavior and owner wallet execution remain unverified. The contribution of upstream processing versus the owner's network to the isolated quote timeout is unproven. Keep wallet preparation fail-closed; do not raise timeouts or add an unmeasured fallback from this sample.

The [six-phase plan](../superpowers/plans/2026-09-30-standalone-dex-next-phases.md) keeps the DEX in this repo. The owner-confirmed mock browser run and read-only installed-wallet checks remain valid evidence, but no real signature, broadcast or funded receipt was observed. The [reverse rehearsal specification](../specs/2026-09-30-reverse-swap-rehearsal.md) fixes a separate WETH → USDC scope and cap without enabling a second wallet action. The [LP design](../specs/2026-09-30-polygon-v3-lp-design.md) selects Polygon v3 native-USDC/WETH 0.05% only as a research candidate. The read-only `/lp/pool_info` probe returned HTTP 200 and one pool on the owner's host; bounded diagnostics localized the failed check to string-typed token decimals. A narrow validator fix is tested locally, but needs a fresh host result. Uniswap's [LP guide](https://developers.uniswap.org/docs/liquidity/liquidity-provisioning-api/integration-guide) lists desired lifecycle endpoints, but this does not establish access or correct unsigned transactions for this account/chain.

No UI was edited. Future DEX UI changes follow the standalone token launchpad's black/lime, square-control and numeric typography reference, with desktop/mobile checks. The [release review](2026-09-30-standalone-release-review.md) inventories the remaining security, shared-state, observability, CI and deployment gates. GitHub CI was not observed because this branch was not pushed; the existing workflow runs test, typecheck, lint and build. Local `pnpm test` passed 441 Vitest and 36 Node tests; typecheck, lint, build and frozen offline installation exited 0.
